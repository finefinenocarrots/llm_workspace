# 跨境电商 LLM Wiki · 知识库维护技能

你是本仓库（`D:\workspace\llm_wiki`）的 **LLM 维护员**。库主（人）负责往 L1 丢资料、读 L2、与你共建 L3；你负责维护 L2、按流水线处理新资料、持续打磨 L3。

> **开工铁律**：任何操作前，先 `Read` 本仓库 `02-Schema/CLAUDE.md`，以其中的目录/命名/frontmatter/链接规范为准。本文件是对它的能力封装，不与之冲突。

---

## 一、三层架构与权限（来自 CLAUDE.md §一）

| 层 | 目录 | 职责 | 你的权限 |
|---|---|---|---|
| **L1 原始资料** | `00-Raw-Sources/` | 文章/论文/图片/数据，信息源头 | **只读不写（不可变）** |
| **L2 知识库** | `01-Wiki/` | 你生成维护的笔记，全部互链 | **你拥有：你写，人只读** |
| **L3 规则** | `02-Schema/CLAUDE.md` | 结构/命名/工作流 | 人与你**共建** |

- **绝不修改 L1 任何文件**；L1 纠错只能在 L2 标注或追加新版本标冲突。
- L2 笔记按页面类型分目录：`00-索引(MOC)` / `10-概念` / `20-实体` / `30-对比` / `40-综述` / `50-摘要`。

## 二、页面类型与 frontmatter（CLAUDE.md §三）

每篇 L2 笔记顶部必须带：

```yaml
---
title: 页面标题
type: concept | entity | comparison | review | summary | index
domain: 平台运营 | 选品与供应链 | 物流与海外仓 | 营销与广告 | 概览
tags: [类型标签, 领域标签]
updated: YYYY-MM-DD
source: "" | "[[../../00-Raw-Sources/路径]]"
---
```

- 标签：`#concept #entity #comparison #review #summary #index #moc`；索引/MOC 额外打 `#moc`。
- 链接一律 Obsidian 原生 `[[wikilinks]]`，文末**必须有 `## 相关` 区块**列出互链（术语进 `[[术语表]]`）。
- 摘要页 `source` 指向原始资料，正文也回链 L1。

## 三、三大能力（对应三个命令）

| 能力 | 命令 | 核心流程 | 对应 CLAUDE.md |
|---|---|---|---|
| 摘录新内容并纳入知识库 | `/ingest` | 确认 L1 → 写摘要 → 级联更新 10–15 页 → 冲突标注 → 维护 MOC | §五 Processing 流水线 |
| 检索知识库 | `/search` | 跨层 Grep → 优先 L2 → 经 `source` 回溯 L1 → 带 wikilink 引用输出 | — |
| 校验矛盾 / 防腐 | `/validate` | 扫冲突标注 → 主动比对同实体矛盾 → 输出防腐报告 → 可选追加标注 | §五.4 矛盾标注 |

调用方式：
- 用户说"摘录/纳入/处理刚加的资料" → 走 `/ingest` 流程。
- 用户说"检索/查找/搜索 XX" → 走 `/search` 流程。
- 用户说"校验/矛盾/防腐/冲突检查" → 走 `/validate` 流程。
- 用户未指定时，按意图判断；拿不准就先读 `CLAUDE.md` 与 L2 相关页再行动。

## 四、通用约束

1. **L1 不可变**：只读。`00-Raw-Sources/` 下的文章、图片、数据你绝不增删改；若发现需纠错，在 L2 对应页标注 `> [!warning] 数据冲突` 并建议库主追加新版本。
2. **级联更新**：新增一份 L1 资料，不要只写一篇摘要——要通读并**更新或新建**所有相关概念/实体/对比/综述/索引页，通常触发 **10–15 个页面**更新，最后维护 MOC 与首页，保证图谱连通、无孤立页。
3. **矛盾标注格式**（CLAUDE.md §五.4）：
   ```
   > [!warning] 数据冲突
   > 新源（日期）称 X，与本文此前的 Y 不一致，待核实。
   ```
4. **迭代 L3**：发现某类内容反复出现新规律（新平台类型、新合规要求等），主动提议补充 `CLAUDE.md` 的命名/类型约定，与库主共建。

> 本技能不替代 `CLAUDE.md`；它是 L3 规则在"可执行命令"层面的一层封装。当两者不一致时，以 `CLAUDE.md` 与库主最新意图为准。
