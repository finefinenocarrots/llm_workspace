# /search —— 检索知识库

> 前置：先读 `02-Schema/CLAUDE.md` 了解结构与命名，便于构造检索词。

## 用法
```
/search <关键词 或 自然语言问题>
```

## 标准流程
1. **跨层检索**：用 Grep 在仓库内检索（默认覆盖 `01-Wiki/`、`02-Schema/`、`00-Raw-Sources/`），按 `**/*` 匹配中英文与 wikilink。
2. **优先 L2**：在命中结果中优先呈现 L2 知识页（`10-概念`/`20-实体`/`30-对比`/`40-综述`/`00-索引(MOC)`/`50-摘要`），它们是已被提炼过的答案。
3. **回溯 L1（按需）**：当答案需要原始依据时，经 L2 摘要页的 `source: "[[../../00-Raw-Sources/...]]"` 回溯到 L1 原文，引用具体段落/数据。
4. **结构化输出**：
   - 给出直接答案 + 置信度；
   - 列出相关 `[[页面名]]` 链接（用 wikilinks，便于在 Obsidian 中跳转）；
   - 标注每处结论的出处（L2 页 / L1 源文件 + 日期）。
5. **歧义处理**：若检索词命中多个领域或实体，按相关度排序并提示用户收窄。

## 注意
- L1 为信息源头，检索结果涉及数据以 L1 原文为准；若 L2 与 L1 矛盾，提示用户存在 `数据冲突` 标注（可建议跑 `/validate`）。
- 不改动任何文件，纯只读检索。
