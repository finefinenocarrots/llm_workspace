# 术语表（Glossary）

> 速查表。每条尽量链到详解页；暂无专页的留作后续补充。

| 术语 | 含义 | 详见 |
|---|---|---|
| **SKU** | Stock Keeping Unit，卖家自定义库存单位 | — |
| **ASIN** | Amazon 标准识别号，Amazon 上唯一标识一个商品 | [[Amazon 平台]] |
| **FBA** | Fulfillment by Amazon，亚马逊代发货 | [[Amazon 平台]] / [[跨境物流模式对比]] |
| **FBM** | Fulfillment by Merchant，卖家自发货 | [[跨境物流模式对比]] |
| **ACoS** | Advertising Cost of Sale，广告花费 / 广告销售额，PPC 核心指标 | [[Amazon PPC 基础]] |
| **CPC** | Cost Per Click，单次点击成本 | [[Amazon PPC 基础]] |
| **ROI** | 投资回报率 | — |
| **GMV** | 商品交易总额 | — |
| **Listing** | 商品详情页（标题 / 图片 / 五点 / 描述） | [[Amazon 平台]] |
| **DTC** | Direct to Consumer，直达消费者独立站模式 | [[Shopify]] |
| **独立站** | 自建电商网站（如 Shopify） | [[Shopify]] |
| **海外仓** | 设在目标国的本地仓库，实现本地发货 | [[跨境物流模式对比]] |
| **托管模式** | 全托管 / 半托管，平台深度参与运营 | [[全托管 vs 半托管 vs 独立站]] |
| **每日预算 / 平均每日预算** | Amazon 广告按"整月平均支出"逻辑执行，单日浮动、月度封顶 | [[广告预算机制]] |
| **Rufus** | 亚马逊站内 AI 智能导购；其新增 Prompts 智购收费广告位 | [[Rufus AI 广告位]] |
| **Prompts 智购** | 嵌入 Rufus 问答的 AI 广告位，2026-03-25 起转 CPC | [[Rufus AI 广告位]] |
| **SPP** | Sponsored Products Prompts，商品推广智购（单品） | [[Rufus AI 广告位]] |
| **SBP** | Sponsored Brands Prompts，品牌推广智购（品牌） | [[Rufus AI 广告位]] |
| **广告漏斗 / 漏斗模型** | 买家从认知到忠诚的购物旅程模型，用于分阶段优化广告 | [[广告漏斗]] |
| **认知/考虑/转化/忠诚** | 广告漏斗四阶段（Awareness/Consideration/Conversion/Loyalty） | [[广告漏斗]] |
| **广泛匹配** | 关键词最宽泛的触发方式，覆盖更多搜索词 | [[关键词匹配类型]] |
| **词组匹配** | 搜索词含设定词组时触发，平衡流量与相关性 | [[关键词匹配类型]] |
| **精准匹配** | 仅高度一致搜索词触发，流量最精准 | [[关键词匹配类型]] |
| **CPM** | Cost Per Mille，每千次曝光成本 | [[广告漏斗]] |
| **CTR** | Click-Through Rate，点击量 / 曝光量 | [[广告漏斗]] |
| **CVR** | Conversion Rate，订单量 / 点击量 | [[广告漏斗]] |
| **ROAS** | Return on Ad Spend，销售额 / 广告支出 | [[Amazon PPC 基础]] |
| **LTV** | Life Time Value，客户终身价值 | [[广告漏斗]] |
| **再营销 / Remarketing** | 向浏览未购买或已购买用户再次投放广告 | [[广告漏斗]] |
| **视频广告（SBV）** | Sponsored Brands Video，以视频形式展示品牌与商品 | [[Amazon PPC 基础]] |
| **品牌商店（Stores）** | 品牌专属多页面购物体验，承载再营销与忠诚 | [[Amazon PPC 基础]] |
