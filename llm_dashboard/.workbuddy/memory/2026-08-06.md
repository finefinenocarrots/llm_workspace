## 7月 W28-W31 费比(TACOS)波动分析
- 新增脚本 `scripts/analyze_tacros.py`：解析 tg_data.js，按周一为周首聚合 7月各周，做 TACOS=CPC/(CVR×AOV) 漏斗分解 + 类目/国家下钻。
- 关键发现（与用户直觉相反）：W28-W31 窗口内**峰值其实是 W28(7/6周,14.3%)**，W29(13.8%)反而比 W28 低0.5pp；中旬(W28-W30)整体比月初W27(12.8%)/月末W31(12.9%)高约1-1.5pp。
- 主因：**账户级 CPC 上行($0.85→$0.91) + 客单价AOV下行($35→$33)** 共同推高费比；CVR 全程平稳(18.7-19.3%)非主因。
- 类目下钻：头部大类(塑封机/不锈钢贴片挂钩)费比稳定，食品真空机反而好转 → 系统性波动而非单类目失控。
- 报告存档：`exports/7月W28-31费比波动分析.md`。
- 复用提示：TACOS 归因统一用 TACOS=CPC/(CVR*AOV) 三因子分解，比单纯看花费/销售更清晰。
