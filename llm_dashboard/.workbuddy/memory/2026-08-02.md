## Pages 部署报错排查 (Resource not accessible by integration)
- 报错位置：actions/configure-pages@v5 的 create-a-pages-site 步骤
- 根因 = GITHUB_TOKEN 无权创建 Pages 站点，非 YAML 语法问题（权限声明正确）
- 两大主因：① 仓库 Settings→Actions→General→Workflow permissions 被设为 Read-only，导致 YAML 的 pages:write 被忽略 → 需改回 Read and write permissions；② 私有仓库无 GitHub Pro/Team 套餐（免费私有库不支持 Pages）→ 改 Public 或升级
- 修复要点：开工作流写权限 + 确认仓库可见性/套餐 + 可在 Settings→Pages 手动 Source=GitHub Actions 开启后删掉 configure-pages 的 enablement:true
- 沙箱无 gh CLI，无法远程查/改仓库设置，需用户在 GitHub 网页端操作
